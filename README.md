# 大模型学习

面向公司内部同事的大模型技术分享项目。

本项目的目标不是培养大模型算法工程师，而是帮助公司内部不同背景的同事建立共同认知：了解大模型的基本原理，理解 RAG 和 Agent 的工作方式，并通过可运行的演示认识大模型如何接入实际业务。

## 分享定位

- 每周分享一次，每次建议 60～90 分钟
- 以演示为主，概念为辅，避免一开始陷入复杂数学和框架 API
- 使用统一案例逐步递进，而不是每周更换完全不同的主题
- 每周既展示成功案例，也展示能力边界和失败情况
- 第一阶段先完成 5 周，后续内容暂不展开

| 周次 | 主题 | 核心目标 |

## 统一演示案例

第一阶段建议围绕“内部项目助手”展开：

> 读取项目资料，回答问题，提取任务，分析风险，并生成项目汇报摘要。

这个案例可以自然地贯穿整个学习过程：

1. 第 1 周用大模型分析需求和 UI 截图
2. 第 2 周让模型查询项目文档
3. 第 3 周让模型调用项目查询或任务创建工具
4. 第 4 周把查询、分析、汇报组织成工作流
5. 第 5 周使用 Agno 将上述能力组装成应用

## 面向不同背景同事的关注点

- 开发相关：模型 API、结构化输出、RAG 服务、工具调用和应用接入
- 设计与内容相关：图片和界面理解、方案发散、素材分类和文案辅助
- 三维与业务协作相关：自然语言控制场景参数、查询资料、需求拆解和风险整理

## 暂不展开

第一阶段暂不重点讨论模型训练和微调、复杂评估体系、生产部署、成本治理、完整安全体系以及多个框架的横向比较。先保证大家能够理解基本原理，并亲眼看到一个大模型应用逐步搭建出来。
