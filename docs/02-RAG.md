# 第 2 周：RAG

## 分享目标

理解模型如何在运行时使用公司内部文档和业务知识。

## 主要内容

- 为什么模型需要外部知识
- 文档导入和切分
- Embedding 的直观含义
- 向量检索和上下文增强
- 回答时引用来源
- 检索不到内容时如何拒答

## 现场演示

准备一组虚构的项目文档，分别演示：

1. 不接知识库，直接询问模型
2. 接入文档后再次询问
3. 询问文档中不存在的问题
4. 放入冲突或过期文档，观察回答变化

## 本周产出

- 一个简单的内部文档问答 Demo
- 一张 RAG 工作流程图
- 一组 RAG 成功和失败案例

## 分享边界

重点是理解 RAG 的完整闭环，不深入比较各种向量数据库，也不讨论复杂的检索评估体系。
