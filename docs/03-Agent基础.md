# 第 3 周：Agent 基础

## 分享目标

理解 Agent 和普通聊天的区别，以及模型如何调用外部工具完成任务。

## 主要内容

- Agent 的基本组成
- 工具调用
- 任务拆解
- 工具输入和输出
- 模型判断与程序执行的边界

## 现场演示

让模型完成以下任务：

> 查询某个项目当前状态，整理进度，识别风险，并生成一份摘要。

其中查询动作由工具完成，模型负责理解用户意图、组织调用参数和整理结果。

## 本周产出

- 一个带工具调用的单 Agent Demo
- 一张 Agent 与普通对话的对比图
- 一个简单工具的输入输出说明

## 分享边界

本周先讲清楚单 Agent 和工具调用，不急于展开复杂的多 Agent 协作。
