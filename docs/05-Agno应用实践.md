# 第 5 周：Agno 应用实践

## 分享目标

将前面学习的 Agent、知识库、工具和 Workflow 组装成一个小型应用。

Agno 官方将其定位为用于构建 Agent 应用平台的 SDK，提供 Agent、Team、Workflow、工具、知识和记忆等能力。学习时重点放在应用结构和运行过程，不把分享变成 API 目录讲解。

## 主要内容

- Agno 解决什么问题
- 创建一个最简单的 Agent
- 给 Agent 增加工具
- 接入第 2 周的知识库
- 使用 Workflow 组织多个步骤
- 通过简单页面或接口调用 Agent

## 现场演示

完成一个“内部项目助手”：

1. 查询项目资料
2. 回答项目问题
3. 提取待办任务
4. 分析项目风险
5. 生成项目汇报摘要

Agno 的 Workflow 支持顺序执行、条件分支、循环和并行等步骤，适合承接第 4 周的工作流内容。

## 本周产出

- 一个可运行的 Agno 小应用
- 一张应用结构图
- 一份从用户问题到 Agent、知识库和工具的调用链说明
