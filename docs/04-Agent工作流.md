# 第 4 周：Agent 工作流

## 分享目标

理解如何把多个 Agent 或多个处理步骤组织成可控流程。

## 主要内容

- 多步骤任务
- 状态和结果传递
- 多个角色的协作
- 顺序执行和条件分支
- 人工确认和执行边界

## 现场演示

构建如下流程：

> 读取项目资料 → 提取任务 → 分析风险 → 生成汇报稿 → 等待人工确认

可以顺带展示三个简单角色：

- 资料整理 Agent
- 风险分析 Agent
- 汇报生成 Agent

重点是理解角色分工和流程控制，不要求深入复杂的多 Agent 调度。
