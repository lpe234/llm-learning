# 第 1 周：大模型基础总览

## 分享目标

让不同背景的同事建立共同语言，知道大模型能做什么、为什么能做到，以及它有哪些边界。

## 主要内容

- 大模型是什么，以及它和传统软件功能的区别
- Token、上下文、训练和推理的直观含义
- Prompt 如何影响模型输出
- 结构化输出：JSON、表格和信息抽取
- 多模态：图片、截图和界面的理解
- 幻觉和不确定性

## 现场演示

准备一份项目需求和一张 UI 截图，让模型完成：

1. 总结需求
2. 提取任务、人员、时间和风险
3. 输出结构化 JSON
4. 分析 UI 截图并提出改进建议

## 本周产出

- 大模型基础概念图
- 一组基础能力演示
- 常用术语表

## 分享边界

本周不深入数学推导，也不展开模型训练和微调。重点是为后续 RAG、Agent 和应用实践建立基础。
