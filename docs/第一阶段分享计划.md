# 第一阶段分享计划

## 1. 计划概述

本阶段安排 5 周，每周分享一次，每次建议 60～90 分钟。

分享对象是公司内部同事，可能来自开发、设计、三维、业务协作等不同背景。课程不以培养算法工程师为目标，而是帮助大家建立共同认知，并通过演示理解大模型的基本原理和应用方式。

课程递进关系如下：

> 大模型基础总览 → RAG → Agent 基础 → Agent 工作流 → Agno 应用实践

## 2. 每周主题

| 周次 | 主题 | 说明 |
| --- | --- | --- |
| 第 1 周 | [大模型基础总览](01-大模型基础总览.md) | 建立共同语言，理解能力、原理、Prompt 和多模态 |
| 第 2 周 | [RAG](02-RAG.md) | 理解模型如何使用内部文档和业务知识 |
| 第 3 周 | [Agent 基础](03-Agent基础.md) | 理解工具调用、任务拆解和执行结果 |
| 第 4 周 | [Agent 工作流](04-Agent工作流.md) | 理解多步骤流程、角色协作和人工确认 |
| 第 5 周 | [Agno 应用实践](05-Agno应用实践.md) | 将 Agent、知识库、工具和 Workflow 组装成小应用 |

## 3. 每周固定结构

| 环节 | 建议时长 | 说明 |
| --- | ---: | --- |
| 上周回顾 | 10 分钟 | 回顾核心概念和演示结果 |
| 概念讲解 | 15～20 分钟 | 只讲理解本周演示所需的内容 |
| 现场演示 | 25～35 分钟 | 展示完整流程，并保留一个失败或边界案例 |
| 场景结合 | 10～15 分钟 | 结合不同同事的工作场景说明实际意义 |
| 讨论答疑 | 10 分钟 | 收集问题，作为后续材料的输入 |

每周至少形成一项可复用成果，例如课程笔记、流程图、演示代码、演示视频或实验记录。

## 4. 统一演示案例

建议整个阶段围绕“内部项目助手”展开：

> 读取项目资料，回答问题，提取任务，分析风险，并生成项目汇报摘要。

统一案例可以让大家看到一个应用如何逐步演化：

1. 第 1 周让模型理解需求和 UI 截图
2. 第 2 周让模型查询项目文档
3. 第 3 周让模型调用项目查询或任务创建工具
4. 第 4 周把查询、分析、汇报组织成工作流
5. 第 5 周使用 Agno 组装成一个小应用

建议使用脱敏或虚构资料进行演示，不直接把未经确认的公司敏感数据放入公开模型或示例代码。

## 5. 第一阶段边界

本阶段暂不重点展开模型训练和微调、复杂评估体系、生产部署、成本治理、完整安全体系以及多个框架的横向比较。

第一阶段的完成标准是：参与者能够理解基本概念，看懂 RAG 和 Agent 的运行过程，并看到一个基于 Agno 的小应用从知识库和工具逐步组装出来。
